# Changelog

Здесь пишется, что изменилось в каждой версии. Раздел с текущей версией из `package.json`
автоматически попадает в `webapp\release.json` и показывается пользователям в окне
«Что нового» при обновлении.

Формат раздела:

```
## 1.1.0 — 12.11.2026
- Первая строка — короткое описание
- Вторая строка — деталь
```

## 1.0.3 — 11.11.2026

- Маршрутизация по приложениям: правило для конкретной программы («Telegram мимо VPN», «Steam через VPN»)
- Каталог категорий сайтов: поиск по 123 категориям geosite с числом доменов, блокировка или «напрямую»
- DNS: выбор серверов (Cloudflare, Google, Quad9, Яндекс, свои) и режим «DNS через VPN (DoH)» — провайдер не подменит ответы
- Квик-виджет: мини-окно поверх всего с кнопкой вкл/выкл, текущим сервером и задержкой

## 1.0.2 — 11.11.2026

- Вход в кабинет в один клик: кнопка «Войти через Telegram» открывает бота со ссылкой подтверждения, приложение входит само
- Ручной ввод кода оставлен как запасной вариант

## 1.0.1 — 11.11.2026

- Обновление ядра Xray прямо из приложения: проверка новых версий на GitHub, скачивание и установка без прав администратора
- Светлая тема и выбор цвета акцента, режим «как в системе»
- Настройки разбиты на разделы: Приложение, VPN, Маршрутизация, Xray, О программе
- Проверка обновлений приложения теперь работает и по расписанию (раз в 6 часов), а не только при запуске

## 1.0.0 — 11.11.2026

- Новая иконка приложения: многоразмерный `icon.ico` (16…256), отдельный значок трея, логотип в шапке
- TUN-режим: весь трафик системы идёт в туннель (нативный TUN-инбаунд Xray + Wintun, Xray поднимается с правами администратора)
- Пресеты маршрутизации: Россия напрямую, блокировка рекламы, трекеров и 18+, Discord, соцсети, YouTube, OpenAI напрямую
- Уведомления Windows: подключение, потеря связи, восстановление, обновления
- Автообновление приложения: проверка новой версии, скачивание и тихая установка
- Вкладка «Что нового» с changelog текущей версии
