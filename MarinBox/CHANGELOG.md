# Changelog

Здесь пишется, что изменилось в каждой версии. Раздел с текущей версией из `package.json`
автоматически попадает в `webapp\release.json` и показывается пользователям в окне
«Что нового» при обновлении.

Формат раздела:

```
## 1.1.0 — 12.11.2026
- Первая строка — короткое описание
- Вторая строка — деталь
```

## 1.0.0 — 11.11.2026

- Новая иконка приложения: многоразмерный `icon.ico` (16…256), отдельный значок трея, логотип в шапке
- TUN-режим: весь трафик системы идёт в туннель (нативный TUN-инбаунд Xray + Wintun, Xray поднимается с правами администратора)
- Пресеты маршрутизации: Россия напрямую, блокировка рекламы, трекеров и 18+, Discord, соцсети, YouTube, OpenAI напрямую
- Уведомления Windows: подключение, потеря связи, восстановление, обновления
- Автообновление приложения: проверка новой версии, скачивание и тихая установка
- Вкладка «Что нового» с changelog текущей версии
