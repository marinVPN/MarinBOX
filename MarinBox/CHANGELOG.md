# Changelog

Здесь пишется, что изменилось в каждой версии. Раздел с текущей версией из `package.json`
автоматически попадает в `webapp\release.json` и показывается пользователям в окне
«Что нового» при обновлении.

Формат раздела:

```
## 1.1.0 — 12.11.2026
- Первая строка — короткое описание
- Вторая строка — деталь
```

## 1.0.7 — 17.11.2026

- Запись панели «Осталось …» снова видна в списке серверов всех подписок — по ней видно остаток трафика и срок
- Она помечена как справка: не выбирается, не пингуется и не используется при подключении
- Счётчик «Серверов» снова считает все строки подписки, вместе со служебной
- Задержки стали честными: серверы проверяются по одному и берётся минимум из двух замеров — без «ступенек» 73/140/207 мс
- Без включённого VPN задержка меряется по TCP до самого узла, а не до тестового сайта напрямую
- Карточка «Задержка» обновляется сразу после проверки и совпадает с числом у выбранного сервера

## 1.0.6 — 17.11.2026

- Исправлено: живая скорость на главном экране не росла — статистика Xray теперь читается по всем счётчикам сразу
- Список серверов больше не показывает служебную запись панели («Осталось - ∞») — только реальные серверы
- Двухбуквенные коды стран убраны из названий: «Швеция #1» вместо «SE Швеция #1»
- Версия ядра Xray видна сразу в настройках, без нажатия «Проверить обновления»
- Счётчик «Серверов: N» учитывает только реальные серверы, вкладки подписок скрываются, если подписка одна
- Светлая тема: контрастный значок протокола; у поля поиска и правил больше нет оранжевой рамки
- Поиск по настройкам: подписи разделов на русском

## 1.0.5 — 16.11.2026

- Исправлено: в настройках была пустая вкладка «Маршрутизация» — правила живут на отдельном экране, лишняя вкладка убрана

## 1.0.4 — 16.11.2026

- Новый главный экран: две колонки, карточка подписки сверху, живые метрики — скорость приёма/передачи, трафик за месяц и задержка
- Живая скорость и трафик считаются самим Xray (stats-API), без сторонних запросов
- Стадии подключения: «Запускаем ядро → Настраиваем прокси → Защищаем DNS»
- Поиск по настройкам по Ctrl+K: поиск по всем полям с переходом к нужному
- Значок трея меняется по состоянию: серый — отключено, зелёный — подключено, красный — ошибка
- Отдельный экран «Маршрутизация» со схемой правил: приложения → категории → исключения
- Единая шкала отступов, размеров текста и скруглений во всём интерфейсе

## 1.0.3 — 11.11.2026

- Маршрутизация по приложениям: правило для конкретной программы («Telegram мимо VPN», «Steam через VPN»)
- Каталог категорий сайтов: поиск по 123 категориям geosite с числом доменов, блокировка или «напрямую»
- DNS: выбор серверов (Cloudflare, Google, Quad9, Яндекс, свои) и режим «DNS через VPN (DoH)» — провайдер не подменит ответы
- Квик-виджет: мини-окно поверх всего с кнопкой вкл/выкл, текущим сервером и задержкой

## 1.0.2 — 11.11.2026

- Вход в кабинет в один клик: кнопка «Войти через Telegram» открывает бота со ссылкой подтверждения, приложение входит само
- Ручной ввод кода оставлен как запасной вариант

## 1.0.1 — 11.11.2026

- Обновление ядра Xray прямо из приложения: проверка новых версий на GitHub, скачивание и установка без прав администратора
- Светлая тема и выбор цвета акцента, режим «как в системе»
- Настройки разбиты на разделы: Приложение, VPN, Маршрутизация, Xray, О программе
- Проверка обновлений приложения теперь работает и по расписанию (раз в 6 часов), а не только при запуске

## 1.0.0 — 11.11.2026

- Новая иконка приложения: многоразмерный `icon.ico` (16…256), отдельный значок трея, логотип в шапке
- TUN-режим: весь трафик системы идёт в туннель (нативный TUN-инбаунд Xray + Wintun, Xray поднимается с правами администратора)
- Пресеты маршрутизации: Россия напрямую, блокировка рекламы, трекеров и 18+, Discord, соцсети, YouTube, OpenAI напрямую
- Уведомления Windows: подключение, потеря связи, восстановление, обновления
- Автообновление приложения: проверка новой версии, скачивание и тихая установка
- Вкладка «Что нового» с changelog текущей версии
